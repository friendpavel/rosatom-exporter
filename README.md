# Росатом — Выгрузка таблицы

Расширение для браузера Chrome (Manifest V3), которое собирает данные о закупках с портала [zakupki.rosatom.ru](https://zakupki.rosatom.ru) и выгружает их в ZIP-архив, содержащий:

- **Детализированная потребность** — Excel-файл (.xlsx) с таблицей потребности
- **Основные данные** — XML-файл со структурой: номер закупки, предмет, заказчики, ОКПД2, ОКВЭД2 и др.
- **Прикреплённые файлы** — все файлы из раздела закупки

## Установка

1. Откройте Chrome и перейдите на `chrome://extensions/`
2. Включите **Режим разработчика** (Developer mode)
3. Нажмите **Загрузить распакованное расширение** (Load unpacked)
4. Выберите папку `rosatom-exporter`

## Использование

1. Откройте карточку закупки на [zakupki.rosatom.ru](https://zakupki.rosatom.ru)
2. Нажмите на иконку расширения в панели браузера
3. Нажмите кнопку **📦 Сохранить всё (Excel + XML + файлы)**
4. Дождитесь завершения — архив будет скачан автоматически

## Структура файлов

```
├── manifest.json      — Манифест расширения (Manifest V3)
├── popup.html          — Интерфейс всплывающего окна
├── popup.js            — Логика сбора и упаковки данных
├── content.js          — Скрипт содержимого (зарезервирован)
├── xlsx.full.min.js    — Библиотека SheetJS для Excel
├── xlsx.mini.min.js    — Мини-версия SheetJS
├── jszip.min.js        — Библиотека JSZip для создания ZIP
└── .gitignore
```

## Технологии

- Manifest V3
- Chrome Extension API (tabs, scripting, downloads)
- SheetJS (XLSX)
- JSZip
- Native JavaScript
